# Contributing

Bug reports and reproducibility checks are welcome through GitHub Issues.

Changes to layout, accessibility, documentation, and tests may be proposed by
pull request. Changes to the intercept, coefficients, predictor definitions,
coding, outcome, or calculation are model changes and must not be merged into
the v1.0 model without documented statistical authorization, a new model
version, and updated verification examples.

Never submit patient-level data, direct identifiers, protected health
information, credentials, or confidential manuscript material.
